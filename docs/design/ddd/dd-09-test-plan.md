# DD-09 测试计划（Test Plan）

## 文档信息

- **版本**：v1.0
- **日期**：2026-10-15
- **阶段**：S2 详细设计（V 模型左半边收口）
- **上游**：`SRS.md` v1.2 §3（FR）、§5（NFR）、§6（CQ）、`docs/requirements/rtm.md` v1.2、`plan/anti-rea-project-plan.md §6`（验证矩阵）
- **范围**：全部 **47 FR + 11 NFR + 5 CQ** 的测试用例设计（计划级），可执行实现留 S3/S4。
- **状态**：初稿

---

## 1. 目的与范围

给出覆盖**全部需求**的测试用例设计，为 S3 编码与 S4 验证提供可执行基线；满足 M2 出口「测试计划覆盖 100% FR」。

## 2. 测试层次与类型

| 代号 | 类型 | 说明 |
| :--- | :--- | :--- |
| UT | 单元测试 | 函数/模块级 |
| IT | 集成测试 | 模块间契约、端到端 |
| FT | 差分/模糊测试 | 原始 vs 保护产物行为一致；fuzz |
| PT | 性能测试 | 开销、规模、预算 |
| AT | 对抗测试 | Ghidra+LLM 攻击模拟、指标 |
| MR | 人工评审 | 文档/可读性/安全检查表 |
| SA | 静态分析 | Schema/SBOM/自身依赖安全 |
| RD | 实测/红队 | 真实部署、EDR/跨版本 |

## 3. 测试环境

- **工具链**：本地前缀 `/opt/<toolchain>`（LLVM 18.1.8、JDK 21、Ghidra 12.1.4 + PyGhidra、Python 3.11、DEAP、Z3）；
- **基准题库**：许可证干净、构建确定、含 ground truth（`benchmark.schema.json`，DD-07 §6）；
- **LLM**：运行环境提供、独立会话、显式出站（CQ-05）。

## 4. 覆盖策略

- 每个需求 ≥1 个测试用例；关键 Must 需求配 UT + IT/FT；
- 端到端场景复用 `e2e-scenario.md §11`（E2E-01…E2E-10）；
- 双向追踪：需求 ↔ 用例 ↔ 设计锚点（回填 `rtm.md`）。
